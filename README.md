# 开箱装车

一台直邮到家的山地车，从纸箱到能骑走。装前轮、装车把、装座管、装脚踏 ——
每一步都能亲手拖、亲手拧，扭矩拧过头会滑丝，左脚踏拧反了会告诉你为什么。

**当前状态：骨架阶段。** 三维已经跑起来（整车加载、取景、轨道控制），
分步引擎与四个交互原语还没接上。下面这份说明记录已经成立的事实，不是计划。

## 已经成立的

- 整车模型加载完成：**755 个具名节点、313 个网格、31 个材质**
- 零件是按真实型号命名的德文节点，例如 `Vorbau_Hope_FR_35mm`（Hope FR 35mm 把立）、
  `Pedal_Funn_Bigfoot_le` / `_re`（左右脚踏）、`ISO_10642_M6x12_Senkkopfschraube`（沉头螺丝）
- 单位标定完成：**1 模型单位 = 1000 mm**。主标尺是 Hope 200mm 刹车碟（前后两片实测 200.22mm），
  花鼓 150 / 110mm 交叉验证。标定后是一台真车：轴距 1155、前轮 735 / 后轮 684（mullet 混合轮径）、
  头管角 65°、把宽 783、曲柄 165、Reach 407 / Stack 642
- 上游静止姿态里前把向左打了 **40.212°**，加载时绕转向轴扶正。两条判据同时成立：
  前轮心 Z 由 31.94mm 归到 −0.7mm，前轴由 [−0.585, 0.274, −0.764] 变成 [0.0004, 0.0009, −1]
- 装配清单 `assets/bike.manifest.json` 与模型逐条对账（`npm run verify`，11 项全过）

### 一条被推翻的假设

模型自带一条 12.02 秒、356 通道的动画 `Holobike_Loop`。它确实是爆炸展开、确实 t=0 为合装态，
一度看上去可以直接反推每个零件的装配方向。**实测不成立**：扣掉车架漂移、在车架局部系里逐件量过之后，
座管的脱离方向是 [0.210, 0, −0.978]（几乎纯横向），而立管轴是 [0.514, 0.858, 0] ——
座管不可能横着装；左右脚踏也朝同一侧飞出，而真实脚踏是各自沿曲柄轴反向旋入的。

那是一段给镜头看的**摊开展示**，不是按真实装配轴的拆解。装配方向一律取自**几何轴**
（立管轴、转向轴、前轴、曲柄轴），已逐条验证。动画留作「拆开看看」的观赏用途。

## 跑起来

```bash
npm install
npm run dev
```

打开 <http://localhost:5174>。
